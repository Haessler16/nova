# NOVA PMS — Dashboard Visual Reference Pack

This folder contains the visual references and implementation instructions for OpenCode.

## Files

- `01-user-reference-dashboard.png` — the screenshot supplied by the user.
- `02-nova-dashboard-concept.png` — generated visual concept for NOVA PMS.
- `NOVA_DESIGN_SYSTEM.md` — reusable visual system and UX rules.
- `NOVA_OPENCODE_VISUAL_BRIEF.md` — implementation sequence, requirements, acceptance criteria, and prompt.

## How to use

1. Copy this folder's contents into the root of the NOVA PMS repository (or keep them in a `/design-references` folder).
2. Open OpenCode in the project.
3. Paste the prompt at the end of `NOVA_OPENCODE_VISUAL_BRIEF.md`.
4. Ask OpenCode to inspect the existing implementation before editing.
5. Review Dashboard first; only then continue with Reception and the other modules.

Important: the PNG files are visual references, not real product data or functional UI. Do not copy sample names, dates, occupancy values, weather, or payment records as production data.
