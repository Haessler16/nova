# NOVA PMS — Notes & Instructions v1
Paquete para OpenCode. Copia `docs/` y `src-starters/` a la raíz del repo y ejecuta `docs/OPEN_CODE_EXECUTION_PROMPT.md`.

**Regla operativa confirmada:** en este contexto `PGTO DIRETO NO HOTEL` significa que el huésped debe realizar el pago en el hotel durante el check-in mediante una **preautorización con tarjeta de crédito**. Es una acción pendiente, no un pago realizado ni una preautorización ya aprobada. El parser nunca ejecuta pagos. El importe debe confirmarse según política del hotel; no inferirlo de la tarifa. No almacenar PAN/CVV.
